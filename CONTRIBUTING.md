# 参与贡献 · Contributing

[中文首页](README.md) · [English README](README.en.md)

## 中文

欢迎修正概念、链接、翻译与版面问题，也欢迎提供适合不同学科的教学例子。大范围重排课程或新增模块前，请先开 Issue 讨论目标、依据和影响范围。

### 报告问题

请复制下面的字段，删掉不适用的项目：

```text
版本：
文件名 / 路径：
页码 / 小节：
问题：
预期结果：
建议修改及依据：
原始来源链接：
系统 / 阅读软件 / Agent 宿主及版本（如相关）：
```

截图请只保留说明问题所需的部分，遮去私人信息。权限或账号问题不要贴密钥、令牌、个人对话、登录状态或未授权文档。

### 提交修改

1. Fork 仓库，新建自己的修改分支
2. 一次聚焦一个主题；区分事实纠正、表达调整和个人建议
3. 保留原始来源、版本条件与作者归属；不把经验改成普遍结论
4. README 或安装指南的中英文版本保持含义一致，链接和路径一起检查
5. 课件修订说明对应版本及页码；若修改正文，也检查图注、备注、讲稿与手册
6. 提交 Pull Request，写清改了什么、为什么改、如何检查；大文件不要直接混入无关代码提交

### 提交前检查

- [ ] 链接与相对路径可打开
- [ ] 内容与来源一致，保留必要的限定条件
- [ ] 图片、引用及新增文件有明确使用依据
- [ ] 不含私人聊天、账号信息、密钥或未获授权的第三方素材
- [ ] 若涉及导出，已打开实际导出的文件检查
- [ ] 提交说明指出尚未测试或仍待核对的范围

本仓库采用分范围许可，提交前请阅读 [LICENSE-SCOPE.md](LICENSE-SCOPE.md)。不要把第三方材料重新标为本项目原创，或用一份统一许可掩盖文件内的例外。

## English

Corrections to concepts, links, translations, and layouts are welcome, as are teaching examples from other disciplines. Open an issue before substantially restructuring the course or adding a module, so its purpose, evidence, and scope can be discussed.

### Report an issue

```text
Release:
Filename / path:
Slide, page, or section:
Problem:
Expected result:
Suggested change and rationale:
Original source link:
OS / reader / agent host and version, if relevant:
```

Crop screenshots to the relevant problem and remove private information. Never include credentials, tokens, private conversations, account state, or documents you are not authorized to share.

### Submit a change

1. Fork the repository and create a branch
2. Keep the change focused; distinguish a factual correction from an editorial choice or suggestion
3. Preserve original sources, version conditions, and attribution
4. Keep Chinese and English documentation aligned, including paths and links
5. For course edits, identify the release and pages; check related captions, notes, scripts, and handbook text
6. Open a pull request describing what changed, why, and how it was checked; keep large binary files out of unrelated changes

### Before submitting

- [ ] Links and relative paths work
- [ ] Sources support the content and its qualifications
- [ ] Images, quotations, and new files have a clear basis for reuse
- [ ] No private data, credentials, or unauthorized third-party assets are included
- [ ] Actual exported files were inspected when the change affects exports
- [ ] Untested or unresolved areas are explicitly noted

Read [LICENSE-SCOPE.md](LICENSE-SCOPE.md) before contributing. Do not relabel third-party content as original project material or obscure exceptions with a blanket license.
