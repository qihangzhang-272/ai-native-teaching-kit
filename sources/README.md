# 课程来源与素材范围

[references.tsv](references.tsv)包含课件备注中的 226 个去重直达 URL，以及各自出现的幻灯片页码。原来源索引有 231 个编号项，部分指向重复 URL；本表采用独立 REF 编号，不替换课件原编号。链接按课程记录保留，包括历史版本与提交哈希；使用时需回到原文核对当前版本。

来源包括官方文档、作者仓库、原视频、书籍、公开作品和信息导航，帮助读者追溯课程依据。

## v1.1.0 原版素材

本版本保留原版 v6 的课件、讲稿、手册和源文件包，也保留其中的第三方截图、官方图表、书页、作品图、作者肖像及来源标注。README 封面和预览直接取自原版课件，不使用另外生成的封面或替换图。

源 ZIP 包含 77 件课程素材与 3 份个人视觉参考。这里的“素材”包括原图、裁片、兼容图和插画，不表示这些文件全部由课程作者原创或采用同一许可。通用视觉技能目录只保存方法文字，不附带课程图像文件。

引用表的 `SOURCE_REFERENCE` 表示记录来源链接与课程使用页码，不判断该来源的哪些文件随原版附件提供，也不授予再分发权。对附件中具体素材的定位，可结合源 ZIP 的素材来源、裁切对应及页面对应记录。

## 使用与增补

第三方材料仍按各自权利和许可处理。课程作者对原课公开的确认不替代第三方许可；引用、署名、可公开访问或随包提供，也不自动授予读者提取和再次分发的权利。

增补素材时，记录文件、使用页码、作者或机构、直达来源、许可依据、允许用途和所做改动。原创技能/代码与原创教学文字的许可范围见 [许可说明](../LICENSE-SCOPE.md)，版本文件与校验值见 [交付清单](../releases/README.md)。
