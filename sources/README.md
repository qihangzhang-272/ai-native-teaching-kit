## 素材台账与状态

已有素材审查汇报指出：源包内 57 张原始来源图片，加上裁片、兼容图、继承插画和个人视觉参考等，总计 80 个图像文件应逐项检查。这个数字来自既有审查汇报，本地因材料落地阻塞尚未复核原 ZIP；不要据此宣称素材已经获准公开。

逐文件台账至少记录：

| 字段 | 要记录的证据 |
| --- | --- |
| 路径与校验 | 原包路径、实际字节 SHA-256、衍生文件对应关系 |
| 使用位置 | 课件页码、讲稿或手册位置 |
| 归属 | 原作者/机构、来源直达 URL |
| 权利依据 | 具体许可页、授权文本、版本或日期、允许用途 |
| 改动 | 裁切、缩放、标注、兼容转换或其他处理 |
| 发布决定 | ALLOW、LINK_ONLY、REPLACE 或 HOLD，及决定人和理由 |

ALLOW 表示已核验授权覆盖实际发布形式；LINK_ONLY 仅保留来源说明与链接；REPLACE 表示要用有权发布的替代素材；HOLD 表示证据或范围仍待核验，不能进入发布包。状态不构成侵权判断。

当前引用表中的 LINK_ONLY 仅描述这个仓库的处理方式，不能视为原图版权审查的结论。80 项图像台账尚未在本地生成，不能用引用表代替。
