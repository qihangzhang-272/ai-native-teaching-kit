# 课程来源与素材范围

[references.tsv](references.tsv)包含课件备注中的 226 个去重直达 URL，以及各自出现的幻灯片页码。原来源索引有 231 个编号项，部分指向重复 URL；本表采用独立 REF 编号，不替换课件原编号。链接按课程记录保留，包括历史版本与提交哈希；使用时需回到原文核对当前版本。

来源包括官方文档、作者仓库、原视频、书籍、公开作品和信息导航。它们帮助读者追溯课程依据，引用不等于获得原素材再分发许可。

## 公开版怎样处理素材

7 份独立公开版文件已制作并通过检验，七件附件已完成上传。公开版保留来源链接，排除第三方图片和头像，以原创教学示意替换必要图层。示意不冒充真实产品界面、作者原图或实验记录。

作者已同意本人头像进入公开包。公开版中的课程内容与原创素材按附件所列范围提供；通用视觉技能只保存方法文字，不附个人角色母版或第三方文件。原 v6 和原始素材包保留，不公开分发。

引用表的 LINK_ONLY 表示仅收录来源说明与链接，不打包该链接对应的第三方原图、截图、书页或文件。它不授予这些材料新的使用权，也不表示第三方为课程背书。

## 后续增补素材

增补打包素材时，记录文件路径、SHA-256、使用页码、作者或机构、直达来源、许可依据、允许用途和所做改动。许可未覆盖实际用途时，保留链接或使用原创替代，不直接附带源文件。
