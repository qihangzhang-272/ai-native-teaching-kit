# 可选讲课角色

## 参考与授权

使用真实讲述者形象、个人 IP 或吉祥物前，先实际查看用户提供且允许本次使用的原始参考。参考是保持形象的依据，不代表任何新姿势、新页面或最终质量已获认可。内部授课、公开展示和开放下载素材是不同用途，不能从一种许可推断另一种。

本包附带作者已明确允许公开的 [原头像与黑鸟参考](../assets/user-lecture-reference.jpg)，及 [Writing Plans](../assets/writing-plans-personalized.png)、[Ladder](../assets/ladder-personalized.png) 两张已确认示例。来源、使用范围与调用方法见 [素材说明](../assets/README.md)。复现本课程时直接读取这些原图，无需再索取头像或访问维护者的私人目录。

本人讲解者的可见特征为深色乱发及钴蓝高光、浅色透明框眼镜、深蓝上衣与猫形图案；黑鸟为黑色小圆鸟、白色大眼、黄色喙，出现在原头像头顶和两张示例中。用原图核对身份与跨页一致性，不能用第三方头像或另造的替代人物。参考不是分层角色母版，也不保证新姿势已通过验收。原头像周围的文字、粗笔触和背景只属于原图，不作为新课件的背景模板。

其他项目可提供自己的获准角色参考或省略人物。描述可见造型即可，不从图像推断真实性格、情绪或身份属性。

## 内容与角色的边界

角色可以参与提问、指向和提醒；每次出现都应帮助理解本页内容。保持可辨认和跨页一致，无需每页放人物。角色只替换约定的通用讲解插画，不能替换官方截图、真实作者照片或其他证据。

原参考里的背景文字、玩笑、标语与情绪表达不自动进入课堂，按本次受众和用途确认。不要编造讲述者经历、评价、承诺或第三方背书。未来作品按当次要求调整，不把一次课程的服装、配色和装饰强制推广到所有作品。

## 逐页检查

放大检查头颈与躯干关系，沿肩—肘—腕—手连续追踪，核对左右、数量、关节、手指和握持物。留意袖口、背景线或遮挡造成的多余肢体。异常局部优先修复；不能可靠修好时更换姿势或移除非必要人物。角色不遮正文、不挡证据，也不挤掉必要解释。
