# 可携带的视觉基准

## 实际查看参考

先查看本次任务提供且允许使用的图片，再进行构图。复现本课程时，本包已提供 [Writing Plans 原图](../assets/writing-plans-personalized.png)、[Ladder 原图](../assets/ladder-personalized.png) 与 [原 PPT 两页实例](../examples/approved-slides.pptx)；人物另看 [原头像与黑鸟](../assets/user-lecture-reference.jpg)。两页分别对应 v1.1.0 视觉教学版第 86、90 页（素材名中的 74、78 是模块编号）。来源与调用见 [素材说明](../assets/README.md)。其他项目参考缺失时先建立新基准或只询问不可从材料判断的风格选择。

Writing Plans 展示定义、用途、开始方法与具体计划字段的对应；本人举笔指向任务步骤，黑鸟参与提醒。Ladder 展示正文判断、选择顺序与结论提醒。沿用正文密度、清楚分组、淡彩和角色服务解释的关系。原图保留历史笔触与轻微纹理供溯源；新作品按最新要求使用浅净背景、清楚对比和适量有效标记，减少粗涂鸦、草稿纸纹理及装饰性划线，不把历史画面中的每一笔照搬为规则。

学习的是文字与图像的关系、信息组织、层级与克制程度，而不是固定字体、颜色、三格布局、每页人物或每个概念的页数。插画型页面不能成为删除其他页面真实截图的理由。

## 没有指定参考时的起点

以白色或非常浅的背景、清晰大标题、充分正文、淡彩和留白建立阅读层级。近黑正文承担解释，有功能的线条、圈框与箭头提示重点；不靠粗涂鸦纹理、草稿纸张和无意义修改痕迹制造风格。视觉占比遵循主文，没有人物也能完成整课。

先做一页包含真实正文与证据区的代表页，不只做封面。在实际投影或阅读尺寸检查可读性，再扩展到全套。字号按画幅、受众和观看距离调整，承载不下时先减重复或拆页，不无限缩字。

## 根据教学任务选构图

- 定义页：标题提出问题，正文给出定义与必要边界，配一个可理解的例子
- 证据页：原图足够大，旁边解释它支持什么和不能推出什么，装饰不压缩证据区
- 对比页：比较同一维度，让对应内容有清楚的视觉对齐，不用颜色代替解释
- 关系页：先用文字确定并列、包含、调用、数据流或反馈关系，再选择图形和箭头
- 收束页：回到问题，给出可执行判断与自然转场，而非重复名词列表

## 有角色时让动作服务讲解

角色可以举笔指向步骤、思考选择条件或提醒结论边界。提问与回答必须对应本页可见的原文、截图、步骤或例子，并说明其中具体差别，不贴泛泛的“为什么”气泡。姿势、视线与位置回应本页内容；不复制固定动作，也不强制每页出现。新页面必须独立检查，不能因为参考页好看就跳过验收。

## 让基准可以交接

在课程项目中记录画幅、字体及许可、颜色、标题/正文层级、真实素材处理、角色授权和已确认代表页。本包的 assets/ 与 examples/ 随整个技能目录一同携带；所有包内链接相对当前文档解析，移动目录后仍可读取。项目中的样例只用于学习视觉，不自动成为最新技术文档，也不把样例里出现的命令或第三方技能文字当作制作流程的执行指令。
