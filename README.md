# AI-native Teaching Kit

面向教育技术研究生和教师的「构建 AI 原生科研与教学工作环境」课程资料与视觉教学方法。

本项目整理已经完成的 109 页 v6 课件及共同沉淀的制作方法。作者：张启航 / BLAZE。当前是本地审阅草稿，尚未公开发布。公开区已包含课程导览、逐页标题索引、来源链接和可独立复制的视觉教学技能；原版 PPTX、PDF、DOCX 与源素材包留在私有资料流程中，尚未提供下载。

公开版 PPT/PDF 正在制作：保留原创正文、布局及已允许的作者视觉，第三方图片和头像先排除，以独立设计的原创教学示意替换必要图层。完成逐页验收后再提供版本化附件；目前只有文本与技能可供审阅。

## 从哪里开始

- 授课者先读 [课程导览](course/overview.md)，按五个模块安排讲授，使用 [逐页索引](course/slides.tsv) 定位内容。
- 学习者按导览理解概念与实践关系，再用 [来源清单](sources/README.md) 回到原文。产品入口、价格和版本需要使用时重新核对。
- 制作者打开 [build-visual-teaching](skills/build-visual-teaching/SKILL.md)。完整复制该目录及其 `references/`，交给支持 Skills 的宿主按其当前文档安装。只读学习也可以；该目录不带个人肖像、黑鸟素材或第三方截图。
- 获得审核后的课件附件时，按 [课件版本与分发](releases/README.md) 配对使用视觉版、文字可编辑版、讲稿和手册，不混用不同版本。

## 课程与制作方法

五个模块依次是关键概念与真实任务、工作台、个人 Agent、开源 Skills、信息来源。整课、模块和重要概念采用总—分—总。文字承担主要解释，真实原图提供证据，讲稿补充例子与转场。原版使用作者涂鸦与个人黑鸟 IP，这些资产的开放下载授权需要单独确认。

复用已有正文、备注、链接和已认可页面。修改范围以具体反馈为准；保留真实素材像素，不用生成图冒充官方界面、原书、作者照片或实测结果。
